# SnapMark

All-in-one screen capture for Windows 10 and 11: numbered steps, highlights, blur and pixelate, auto-redact, pin to screen, text grab (OCR), color picker, Before/After and Beautify studio with device mockups, step-by-step PDF guides and one-page client reports.

## Download

Get **SnapMark-win-Setup.exe** from the [latest release](https://github.com/kamrancreation/SnapMark-releases/releases/latest) and run it. No admin rights needed; SnapMark updates itself when a new version is out.

Windows may show "Windows protected your PC" because the installer isn't code-signed yet: click **More info → Run anyway**.

This repository only hosts installers and update files.
