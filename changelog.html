Release notes

What's new in SnapMark

SnapMark updates itself: when a new version is ready, you'll see an update popup, and one click installs it.

  1. 1.1.1 Latest 2 October 2026

    Your screenshot, clearly framed

    • Improved The editor now shows your screenshot inside a clear frame with a soft shadow, so even dark screenshots never blend into the app. The frame is only on screen, never in the saved image.
    • Improved A dotted canvas behind the screenshot, in both dark and light themes, shows exactly where the image ends.
    • New A size label above the screenshot shows its width and height, and updates after cropping.
  2. 1.1.0 2 October 2026

    Light mode, text styles and a cleaner editor

    • New Light and dark themes. Pick Dark, Light or Match Windows in Settings → Look and saving, or tap ☀ / ☾ in the app window.
    • New Text styling: choose a font, bold or italic, and Plain, Shadow, Box or Pill labels with a background color.
    • New The editor remembers your tools: your last tool, and each tool's color and size, are still there next time.
    • Improved Screenshots now open straight in the editor. You can switch back to quick actions in Settings → Capture.
    • Improved A cleaner editor toolbar: all tools on one row, and Copy, Save and Save as highlighted with icons.
    • Improved Copy and Save show a "Copied" / "Saved" confirmation, then Done closes without extra questions.
  3. 1.0.1 30 September 2026

    A friendlier way to update

    • New An Update ready popup with Restart now, Later and What's new, instead of a small Windows notification. You'll see it from the next update onward.
    • New The app window shows which version you have, under the SnapMark logo.
    • Improved SnapMark looks for updates 5 seconds after it starts, so new versions arrive sooner.
    • Improved Updates download only the parts that changed. This one is about 0.2 MB.
    • Improved Release notes in Settings → About and updates now opens this page.
  4. 1.0.0 30 September 2026

    First public release

    Capture

    • Custom region, full screen, active window and all screens, at full native resolution.
    • Grab text from anything on screen (OCR) and pick any color as HEX and RGB.
    • Your own shortcuts, a customizable capture menu, an optional 3, 5 or 10 second delay, and PNG or JPEG quality settings.
    • A quick-actions popup after each capture: edit, copy, save, pin, beautify, add to a guide, or create a report.

    Edit

    • Numbered steps, highlight, pixelate, blur, box, arrow, text, pen, spotlight and stamps.
    • Select, move, resize and delete annotations; crop; unlimited undo.
    • Auto-redact finds and hides emails, phone numbers, card numbers, API keys and passwords.

    Share

    • Before / After and Beautify studio with browser, laptop and phone frames, backgrounds and your logo.
    • Step-by-step guides and one-page client reports as print-quality A4 PDFs.
    • Library of your screenshots: copy as file, export several as one PDF, pin to screen.

    App

    • One-click installer, Start menu entry, start with Windows, and automatic updates.
